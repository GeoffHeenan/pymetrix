# Features

What pymetrix does, area by area, and what is only planned. For the checks behind the numbers see
[validation.md](validation.md); for what is missing, [known-gaps.md](known-gaps.md).

## Status (version 0.1.0a19)

Each feature carries a proposed maturity tier (for the project lead's approval):

- **stable**: its numbers are checked against an independent implementation (the wrapped library, another
  package's recorded output or a published table), and it is on the main, well-used path (data, single equations,
  standard tests, VARs and VECMs, forecasting rounds, projects and replay, reports);
- **beta**: validated in tests but with little real use so far, or checked only by hand formulas, simulation or
  published moments rather than another package's output;
- **experimental**: working but thinly checked, likely to change, or with notable known gaps.

Planned work not begun is marked **not started**.

What each feature is checked against is in [validation.md](validation.md); what is missing or rough, in
[known-gaps.md](known-gaps.md). Help pages show the same tier under their summary.
